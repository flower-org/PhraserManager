# Rationale

In today's world, password management is more critical than ever.  
A password is a basic unit of security and as such is omnipresent.  
The password is the first thing you enter when you turn on your computer or smartphone.  
In one way or another, the basis to access your accounts on any resource involves authentication through a password.

Over the decades of digital era, hundreds of methods for unauthorized access to systems have been invented, and a significant portion of them involve attacks on passwords. Video blogger Jack Rhysider released a great video about the variety of such attacks, the summary of which I wrote down [here](APDX_C.%2064%20ways%20to%20obtain%20passwords%20by%20Jack%20Rhysider.md).

## 1. Basic Attack Methods

Let's consider the most basic password attack methods:
1. Brute Force;
2. Dictionary Attack;
3. Credential Stuffing – an attack that involves reusing compromised passwords from one resource to gain access to other resources belonging to the same person;
4. Obtaining the password directly from the user using social engineering methods.

From this minimal list of the simplest threats, we can form basic requirements for password management policies:
1. A password should always be present;
2. Passwords should be sufficiently long and random to prevent brute-force and dictionary attacks;
3. A unique password is required for each resource to prevent Credential Stuffing;
4. Ideally, the user should not know their password to minimize the risk of social engineering. Note that the 4th item in Jack Rhysider's list of ways to obtain passwords – "Ask for the password" – is not a joke;
5. It should be possible to quickly replace a password when there is any sign of potential compromise, with the new password also meeting all security requirements.

It is easy to see that even this minimal list of requirements is almost impossible to meet for a human being without special tools.
The main problem lies in the limitations of human memory: for the vast majority of people, it is inconceivable to physically remember complex, long, unguessable passwords for dozens of accounts and devices, let alone regularly update them in memory.
The human brain simply isn't suited for such tasks unless we're talking about a special talent, 1 in tens of millions.


## 2. Existing Solutions

Popular solutions can be divided into 3 categories:

1. Network Password Managers
   - Web-based 
     - LastPass
     - Dashlane
     - 1Password (Web version), etc.
   - Desktop
     - 1Password (Desktop app)
     - Dashlane (Desktop app)
     - Bitwarden (Desktop app), etc.

2. Offline Password Managers
   - KeePass
   - KeePassXC
   - Password Safe, etc.

3. Mobile Password Managers
   - LastPass (Mobile app)
   - 1Password (Mobile app)
   - Dashlane (Mobile app), etc.

All of these approaches share a few common drawbacks:

1. Lack of Isolation.  
All these solutions operate on the same system that is used for direct access to the resources authenticated by these passwords.
Thus, when that system is compromised, the MasterPass or its equivalent and the entire password database are also compromised.


2. Need for Network Connectivity for Network and Mobile Password Managers.  
If something is connected to the network, it's impossible to exclude the theoretical possibility of compromise, whether directly or indirectly.
There's also the "chicken and egg" problem: to access your passwords, you need to connect to the internet, but shouldn’t we be using a password to access our internet in the first place?  
How about the OS password, the password for the encrypted hard disk, or BIOS?  
In practice, in most cases, the possibility of compromise through the internet also exists for Offline Password Managers, as they too run on the same system, which is likely connected to the internet.


3. Need for Manual Replication of the Password Database for Offline Password Managers.  
For use on more than one system or when reinstalling systems, the password databases of Offline Password Managers need to be manually copied and restored.
Any changes to the password database on one system require manual synchronization/updating on other systems.


## 3. How Phraser Solves All These Problems

Phraser is an innovative approach in which the password manager is implemented as a standalone USB Security Token.

### 3.1 Comparison with Current Systems

1. Phraser is a standalone device that is recognized by the system as a USB keyboard. It is completely isolated and communicates with the main user system by exchanging only the necessary information via a USB connection. All passwords are stored in the memory of the Phraser itself, and even if the main computer or smartphone is compromised, the best-case scenario for the attacker would only be the compromise of passwords entered on that computer, not the entire password database or Master Password.

2. Phraser never directly connects to the internet, as it simply has no network functionality. Therefore, it is considered an Offline Password Manager. Since Phraser is an external USB device, it can be used to store and enter any passwords – including for the OS, hard disk, or BIOS – without requiring an internet connection.  
(Disclaimer – currently, there is a technical issue with detecting a keyboard at the BIOS level, but manual password entry from Phraser is possible, including for BIOS).

3. A single Phraser device can serve multiple computers or smartphones simultaneously, simply by connecting it via USB wherever a password needs to be entered; there is no need to copy or synchronize the password database.

### 3.2 Compliance with Basic Password Requirements

1. The Phraser device stores passwords in its memory;
2. Passwords are generated in accordance with security requirements, are random, and are resistant to brute-force or dictionary attacks;
3. Phraser can store passwords for multiple resources such as web portals, OS, encrypted disks, or BIOS; 
   - Moreover, Phraser can also store data like Security Questions/Answers.
4. Passwords are never shown to the user and are entered with a single button press.
5. Password regeneration is also performed with one press.
   - Furthermore, Phraser keeps a history of changes to data/passwords for each resource, as much as the block size allows (on average, about 15 history records per resource).

## 4. Security of Data Storage on Phraser

- The Phraser database is **ALWAYS** encrypted. An innovative two-layer encryption approach is used with KeyBlock and AES-256 encryption.
  - Therefore, even if physical access to the device is obtained and the database is downloaded without permission, decryption of the database would still be required to access the password data.
- The secure format of the Phraser database eliminates metadata leaks.
- The primary encryption key is derived from the Master Password using the PBKDF2 algorithm. To further enhance security, Phraser allows the user to define the number of PBKDF2 iterations (`UP`+`A`+`B` on Unseal).
- To provide additional isolation of resource groups and their passwords, Phraser supports up to 3 independent password banks, each containing a separate password database with its own unique Master Password (`DOWN`+`A`+`B` on Unseal).

## 5. Issues Specific to Phraser

The biggest issue with Phraser compared to Network Password Managers is that by default, it is a Single Point of Failure.
Indeed, if an accident occurs in which the Phraser device is physically destroyed or permanently lost, the password database will be lost with it.
To minimize the consequences of such a rare but possible mishap, the Phraser device supports a Backup DB function.
In this case, the password database stored on the device will be copied to an external computer via USB.

For this to work, the [Phraser Manager](https://github.com/flower-org/PhraserManager/releases/latest) software must be installed on the computer, which supports a special serial protocol and can save the data received via USB to a file.  
Note that although the database is transferred to the computer in an encrypted form, we recommend performing this operation on an offline machine.  
We also recommend encrypting the backup file for secure storage, to fully prevent the possibility of brute-forcing your Master Password if the backup file is stolen from your storage.  
After such encryption, the original backup file should be destroyed using special software, such as [wipe](https://packages.debian.org/bookworm/wipe) or an equivalent for your OS.  

You could of course store the DB as is – as mentioned, the database is already encrypted – but if you want to _maximize_ the difficulty for potential attackers, please follow the above recommendations.

In the future, in the event of an accident or data corruption, the backup can be restored on the same or a new Phraser device using the Restore DB function.

Of course, this is a manual action, but it is the minimal amount of manual work required only to periodically create backup copies, without manual synchronization.
At the same time, the level of security for passwords provided by Phraser is unprecedented.
Some users may appreciate that this is all done offline, and that their backup files with passwords literally belong only to them, not to any corporation or agency.


# 6. Conclusions

In the face of growing password security threats, managing passwords has become critically important. 
Traditional methods of storing passwords, such as network and offline password managers have their drawbacks, including vulnerability to compromise along with the main system via the internet and/or the need for manual synchronization of data.
Phraser offers an innovative solution, representing a USB Security Token isolated from the main system and not requiring an internet connection, which ensures the highest level of security.

Phraser meets all the basic password security requirements: it generates complex passwords, stores them in a secure way, and allows the user to be oblivious of their textual representation. Moreover, the device supports a backup function, minimizing the risks of data loss. Despite the need for manual backups, the level of security that Phraser provides is unprecedented and allows users to control their data without relying on third parties.

Thus, Phraser represents a unique, reliable, and secure solution for password management in the face of increasing threats in the modern digital world.
